# CRM для компании по продаже мобильной техники

Учебный проект на платформе 1С:Предприятие 8.3. Подсистема CRM для менеджеров по продажам: переговоры, напоминания и вся история по клиенту в одном месте.

## Что реализовано

- Справочник «Статусы» и статус контрагента (потенциальный, действующий, не работаем). В заказе покупателя выводится предупреждение, если с клиентом больше не работаем.
- Документ «Взаимодействие»: звонок, встреча, почта, мессенджер, с выбором ответственного лица контрагента.
- Регистр сведений «Напоминания» с датой, описанием и признаком выполнения.
- Регистр «Документы по контрагентам»: заказы, отгрузки, платежи и взаимодействия собираются в одном списке.
- Накопительная скидка: регистр «Условия скидок», процент считается по продажам клиента за год. В проведённом заказе он не пересчитывается.
- Печатная форма «Счёт на оплату» с логотипом и скидкой.
- Отчёт «Продажи по покупателям» на СКД с группировкой по статусу.

## Как запустить

1. Скачайте файл `.dt` из раздела Releases.
2. Создайте пустую информационную базу.
3. В Конфигураторе выберите Администрирование → Загрузить информационную базу и укажите файл.
